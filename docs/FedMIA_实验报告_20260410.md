# FedMIA 成员推理攻击实验报告

**实验平台：** FederatedScope
**数据集：** CIFAR-100

---

## 一、实验背景

### 1.1 研究问题

联邦学习（Federated Learning）中，**成员推理攻击（Membership Inference Attack, MIA）** 是评估系统隐私安全的重要手段。攻击者试图判断某个样本是否参与了模型训练，从而推断用户隐私。

### 1.2 FedMIA 攻击框架

本次实验复现了 **FedMIA** 联邦学习成员推理攻击框架，包含 **8 种攻击变体**：

| 攻击方法 | 攻击信号 | 特点 |
|----------|----------|------|
| Blackbox-Loss | 单轮损失值 | 基础基线 |
| Grad-Cosine | 梯度余弦相似度 | 需要全局模型 |
| Grad-Diff | 梯度差异 | 需要全局模型 |
| Grad-Norm | 梯度范数 | 需要全局模型 |
| Loss-Series | 多轮损失序列 | 跨轮次聚合 |
| Avg-Cosine | 多轮余弦平均 | 跨轮次聚合 |
| **FedMIA-I** | CDF归一化损失 | 使用Shadow模型估计分布 |
| **FedMIA-II** | CDF归一化余弦 | 使用Shadow模型估计分布 |

## 二、实验设置

### 2.1 数据配置

| 参数 | 值 |
|------|-----|
| 数据集 | CIFAR-100 |
| 客户端数量 | 10 |
| 数据分布 | **Non-IID (Dirichlet α=0.5)** |
| Target Client | Client 1 |
| 总训练样本 | 39,996 |
| 测试集样本 | 10,000 |

**数据异构性说明：**
- α = 0.5 表示**强异构性**
- 各客户端标签分布严重偏离全局分布
- 每个客户端数据量：3,419 ~ 4,502（变异系数 7.8%）

### 2.2 模型配置

| 参数 | 值 |
|------|-----|
| 特征提取器 | ConvNeXt-Base（冻结） |
| 分类器 | MLP Head (1024 → 256 → 100) |
| 训练轮次 | 300 |
| 本地训练步数 | 1 epoch/round |
| 学习率 | 0.01 |
| 每轮采样客户端数 | 3 |

### 2.3 攻击设置

| 参数 | 值 |
|------|-----|
| 攻击者角色 | 被动服务器 |
| 目标客户端 | Client 1 |
| Shadow 客户端 | Clients 2-10 |
| 评估模式 | test mode |

## 三、实验结果

### 3.1 模型训练结果

| 指标 | 值 |
|------|-----|
| 最终测试准确率 | **76.23%** |
| 总训练时间 | ~166 分钟 |
| 训练轮次 | 300 |
| Target Client 采样轮次 | 89/300 |

### 3.2 攻击性能对比

| 攻击方法 | AUC | TPR@0.1 | TPR@0.01 | TPR@0.001 |
|----------|-----|---------|----------|-----------|
| Blackbox-Loss | 0.5825 | 0.1578 | 0.0171 | 0.0052 |
| Grad-Cosine | 0.7568 | 0.3254 | 0.0416 | 0.0130 |
| Grad-Diff | 0.5369 | 0.1211 | 0.0196 | 0.0092 |
| Grad-Norm | 0.5364 | 0.1211 | 0.0182 | 0.0090 |
| **Loss-Series** | **0.7511** | 0.6882 | **0.6168** | **0.5608** |
| **Avg-Cosine** | **0.8316** | 0.6130 | 0.4123 | 0.3607 |
| FedMIA-I | 0.7754 | 0.4853 | 0.2010 | 0.0041 |
| **FedMIA-II** | **0.7908** | 0.6029 | **0.4829** | **0.4430** |

### 3.3 关键发现

**最佳攻击方法：**

1. **Avg-Cosine (AUC=0.8316)**：跨轮次聚合梯度余弦相似度，性能最优
2. **FedMIA-II (AUC=0.7908)**：CDF归一化 + Shadow分布估计，在低FPR下表现最佳
3. **Loss-Series (AUC=0.7511)**：跨轮次损失聚合，简单有效

**低FPR场景表现（TPR@FPR=0.01）：**

| 攻击方法 | TPR@0.01 |
|----------|----------|
| Loss-Series | **0.6168** |
| FedMIA-II | 0.4829 |
| Avg-Cosine | 0.4123 |
| FedMIA-I | 0.2010 |

## 四、技术实现与调试

### 4.1 实现架构

```
federatedscope/
├── attack/
│   └── worker_as_attacker/
│       └── fedmia_server.py      # 攻击服务器（核心）
├── contrib/
│   ├── data/
│   │   └── cifar100_features.py  # 离线特征数据加载
│   └── model/
│       └── mlp_head.py           # MLP分类头
└── extract_features.py           # 离线特征提取脚本
```

### 4.2 关键技术点

**1. 离线特征提取**
- 使用 ConvNeXt-Base 预训练模型提取 1024 维特征
- 避免每轮重复计算，节省训练时间
- 模型冻结，仅训练 MLP 分类头

**2. Per-Sample 梯度计算**
- 使用 Opacus 库计算每个样本的梯度
- 支持梯度余弦、梯度差异、梯度范数三种特征

**3. CDF 归一化攻击（FedMIA-I/II）**
- 使用 Shadow 客户端估计 Q_out 分布
- Per-sample 计算 μ 和 σ
- 通过 CDF 归一化消除尺度差异

### 4.3 Bug 修复过程

**问题1：Shadow Client 过滤错误**
- 现象：FedMIA-I/II TPR@低FPR 全为 0
- 原因：代码中 `client_id == 0` 判断错误（FS 的 ID 从 1 开始）
- 修复：改为 `client_id == self.target_client_id`

**问题2：梯度特征缺失**
- 现象：Shadow 客户端的 `tarin_cos` 为空
- 原因：仅为 Target Client 计算梯度特征
- 修复：为所有客户端计算梯度特征

**问题3：单轮攻击失效**
- 现象：最后4个攻击结果全为 nan
- 原因：最后一轮 Target Client 未被采样
- 修复：添加 `_get_last_valid_round()` 找到最后一个有效轮次

## 五、与原始 FedMIA 对比

### 5.1 实现对齐

| 组件 | 原始 FedMIA | FederatedScope 实现 |
|------|-------------|---------------------|
| 数据集 | CIFAR-100 | CIFAR-100 ✅ |
| 模型 | ResNet-18 | ConvNeXt-Base + MLP ✅ |
| 攻击变体 | 8种 | 8种 ✅ |
| Shadow模型 | 客户端模型 | 客户端模型 ✅ |
| CDF归一化 | Per-sample | Per-sample ✅ |

### 5.2 结果对比（IID 设置）

| 攻击方法 | 原始 FedMIA AUC | 本次实验 AUC |
|----------|-----------------|--------------|
| lira (FedMIA-I) | 0.83 | 0.78 |
| lira_loss | 0.72 | 0.75 |
| cosine attack | 0.82 | 0.76 |

**差异原因：**
1. 数据异构性更强（α=0.5 vs IID）
2. 模型架构不同（MLP vs ResNet-18）
3. Target Client 采样率较低（89/300）

## 六、结论与展望

### 6.1 主要结论

1. **FedMIA 攻击在 Non-IID 场景下有效**：AUC 最高达 0.83
2. **跨轮次聚合攻击更有效**：Loss-Series 和 Avg-Cosine 优于单轮攻击
3. **FedMIA-II 在低 FPR 下表现最佳**：TPR@0.01 = 0.48
4. **模型准确率与隐私风险正相关**：测试准确率 76% 情况下仍存在隐私泄露

### 6.2 隐私风险分析

- **高隐私风险**：AUC > 0.8 表示成员隐私可被有效推断
- **低 FPR 攻击可行**：TPR@0.01 > 0.4 表示在严格控制误报时仍有威胁
- **被动攻击有效**：服务器无需修改训练过程即可发起攻击
